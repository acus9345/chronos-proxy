# Second-Pass Engineering Code Review (`CODE_REVIEW.md`)

After completing the initial implementation of **ChronosProxy**, a full second-pass security, memory-safety, binary-framing, and UI correctness audit was conducted across `src/` and `src/ui/inspector.html`. Every defect identified below was fixed and verified via automated tests in `test/chronos.test.ts`.

---

## Summary of Findings & Applied Fixes

| ID | Severity | Module | Finding | Applied Fix |
| :--- | :--- | :--- | :--- | :--- |
| **CR-01** | **High (Bug / Auth)** | `src/proxy-server.ts` | `replayFrame()` originally re-sent `original.request.headers`, which had already been passed through `redactHeaders()`, causing replayed requests to send `Authorization: Bearer [REDACTED_BY_CHRONOS]` to the upstream server. | Added an unexported in-memory `rawReplayVault` (`Map<string, RawRequestVaultEntry>`) keyed by `frame.id` that preserves raw outbound headers and body buffers for replay while keeping all serialized `TimelineFrame` JSON, exports, and SSE broadcasts strictly redacted. |
| **CR-02** | **High (Data Integrity)** | `src/sqlite-engine.ts` | When a `-wal` file existed during `captureSnapshot()`, its bytes were concatenated onto `rawBuf`. Calling `restoreSnapshot()` wrote the combined `fileSizeBytes` back into the main `.sqlite` file while also deleting `-wal`, breaking SQLite page alignment. | Added `mainDbSizeBytes` to `SqliteSnapshot` and sliced `fullReconstructed.subarray(0, snap.mainDbSizeBytes)` during `restoreSnapshot()` so the restored main `.sqlite` file is strictly page-aligned before unlinking `-wal` and `-shm`. |
| **CR-03** | **Medium (Memory Leak)** | `src/sqlite-engine.ts` & `src/proxy-server.ts` | Evicting old frames when `this.frames.length > this.config.maxFrames` left orphaned `SqliteSnapshot` objects and unreferenced 4KB `Buffer` chunks in `this.pageStore` indefinitely. | Implemented reference-counted garbage collection (`pruneSnapshots(retainedSnapshotIds)`) in `CoWSqliteEngine` and wired `gcUnreferencedSnapshots()` + `rawReplayVault.delete()` into `ChronosProxyServer` ring-buffer eviction. |
| **CR-04** | **Medium (Protocol)** | `src/proxy-server.ts` | Clients sending `Accept-Encoding: gzip, br` caused upstream servers to return compressed binary streams that corrupted UTF-8 JSON capture and structural diffing; re-sending upstream `Transfer-Encoding: chunked` alongside buffered `res.end()` caused framing conflicts. | Forced `forwardHeaders['accept-encoding'] = 'identity'` on upstream requests, stripped `transfer-encoding` / `content-length` before `res.writeHead()`, and added a hard `413 Payload Too Large` guard (`maxBodyBytes * 8`). |
| **CR-05** | **Medium (Diff Logic)** | `src/diff-engine.ts` | 1) Transitions between `null` and primitive values (`null -> "settled"`) were classified as `type_mismatch` instead of `changed` because `typeof null === 'object'`. 2) `compareRowMutations` used `Array.prototype.includes`, missing duplicate mutations with identical signatures. | Refined `walkDiff()` to distinguish structural containers (`object`/`Array`) from nullable primitives, and upgraded `compareRowMutations()` to use multiset frequency maps (`Map<string, number>`). |
| **CR-06** | **Medium (XSS / DOM)** | `src/ui/inspector.html` | User-entered request paths, headers, and table values from the interactive Dispatch Sandbox were interpolated directly into `.innerHTML` templates without HTML entity escaping. | Added `escapeHtml()` in `src/ui/inspector.html` and sanitized all dynamic path, header, mutation column, and table cell strings prior to DOM insertion. |
| **CR-07** | **Low (Build Tooling)** | `scripts/build-ts.mjs` | The regex stripping TypeScript `as Type` assertions accidentally matched `import * as http from 'node:http'`. | Added negative lookbehind `(?<!\*)` so namespace imports (`import * as ...`) are preserved untouched. |
